# Three eastern trade-edge scenes

Source-only additions beside the three actually placed Native55 compounds:

- **East Coal:** actual grindstone, waiting bench, small supported warm lamp,
  new waxed hardware sign and two rooted modded flowers/shrubs on the slope.
- **Shoal Warden:** shallow open pilot-chart canopy, real cartography table,
  ledgers, seating, supported task light and a contained tropical fern.
- **Thin Sail:** actual loom, sewing perch, rooted blossoms, contained plumeria
  and a small independently founded sign/light timber.

The new tool emits separate exact before, dry-support, placement, normal-survival
and full-after files. Existing Native55 geometry is a hash-marked read-only
overlay on the authenticated stopped6ad terrain; no existing BE/NBT/Items is
replayed. Every approved future main-building floor is excluded. Three new sign
tags contain only waxed lettering. No automatic planter, sapling, entity or
invented inventory is used.

The private producer must require a fresh serialized native before/support pass.
Any later human or construction drift stops placement; the old checkpoint is
not authority to erase it. The Coal doorstep's existing curved corbel is retained
and excluded from the new clear-shoulder proof. Native plant survival, precise
model collision, actual rendered views and owner art acceptance remain pending.

`tests/test_eastern_three_detail.py` checks preservation, registered property
domains, supported details and the two-high visiting body. The fixture is block
schema only and contains no world, seed, inventory or saved terrain.
