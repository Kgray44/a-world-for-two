# One Rose Reach street pilot

The new seven-house Rose Reach is east of the retained Signal Lane. A view from
x1271 shows the older Signal building, not acceptance of this new quarter. The
real new lane begins around1292,−1240; actual floor-level views are still needed.

This small source prototype extends the existing graded approach with a paved
return and a two-wide chartmaker alley that bends around the retained fern
stand. It adds shallow carved plant niches between real casements, attached ivy,
rooted flowers, contained pots, one short berry-lit cherry arbor and a tiny jar
and basket display. It preserves the accepted stairs and six-paver connection.
The arbor covers one metre of street depth, leaving the sky open beyond it.

Every floor and walking-body position is read from the clean stopped e55
archive. Natural soil and ordinary grass cover may change only at the exact
listed targets. Existing paving, window views, furniture, block entities,
interiors, the actual HOME bed and all supplied neighborhood/zipline source
reservations are preserved. A finite list distinguishes newly authorized
exterior construction-clearance AIR from protected room/route AIR.

The decorative basket is the native manual Supplementaries lunch basket with
its exact registered normal properties and no supplied inventory. The earlier
Farmer's Delight collector option was rejected: its pinned class uses native
neighbor redstone checks and collection, so setting `enabled=false` alone would
not prove that collection remains disabled. No invented disable-NBT is used.

The retained-context file is explicitly an **observed preservation snapshot**.
It retains existing native default properties, automatic roof/support
connections and the previously authorized bed. It is not a correction of old
roof expectations, a canonical settlement plan or a native acceptance result.
It must never be placed or replayed.

Only the pilot proposal contains new placement targets. KG's current game is
never read or modified by this producer. Every historical preimage must pass
fresh native admission after the owner finishes; later player changes must
refuse the operation. Plant survival, normal joining, actual inventory custody,
a continuous walk and day/night shader composition remain separate gates.
