# First living cohort: accepted old town and quiet woodland

`tools/artistic_first_life_cohort.py` prepares a small **source-only** first living cohort. It reuses the existing v3 native LIFE engine, its 64-member managed cap, the exact sixteen-profile/fifteen-enabled-species curation and the original population namespace. It does not create another controller or population, install a request, grant readiness or spawn anything.

The starting locations are the earlier independently measured woodland/shore/refuge study. They are only locators: complete current FULL saved fields, actual footing, source water, plant/perch evidence, nearby residents and the entire active tree field/roaming approach are checked again. Known cells are never replaced by heightmaps or assumed AIR. Actual original residents, passengers, objects, nests and player changes are preserved. Historical butterfly, dragonfly and allay locations intersect active tree work and stay held for a later separate habitat review.
