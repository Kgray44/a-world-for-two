# Guardian fountain: recovery from actual game review

The native42 photographs exposed a composition problem: the isolated lancet arch
looked like an antenna, a tall L of plumbing dominated the side, the upper water
spread into curtains, and the wheel enclosure blocked the eastern view. Passing
geometry checks did not make that prototype an accepted centerpiece.

`tools.artistic_fountain_centerpiece` is a separate, original R5 proposal. It
retains the previous source and all failed native receipts. It does not operate
the game, write a world, seed entities, or qualify its own appearance.

The composition has one actual three-part Dawn marble Mars statue, facing the
arrival. This is the installed classical statue model, used as a harbor guardian;
it is not advertised as a newly authored Neptune model. A narrow coffered crown,
fluted pilasters, scrolled corbels, two subordinate gargoyles and warm modeled
lanterns tie it to a stepped pale-stone pedestal. The old arch and miniature crest
figures are removed. The reflecting pool is chamfered more strongly, with shaped
coping, while the established seating, garden objects and public approaches stay
in place. Pale carved marble, quartz and inlaid calcite share one visual family;
aged copper is limited to the small service hood rather than random crossing bars.

The focal architecture uses actual Dawn and Mythrais models with Rechiseled and
Chipped masonry. Retained Handcrafted seating, Supplementaries ornaments, Macaw
fixtures and the working Create machinery belong to the same plaza. Each model
still needs actual scale, support, collision, lighting and joining review in the
game. A block or mod count is not an artistic-quality score.

## Hydraulic changes and preserved controls

The complete native R3 startup already proved real wheel−8RPM, pump+8RPM, a pumped
header and all four falling-water witnesses without overstress. The STOP phase
failed. Independent native probes showed dust15/14/13 feeding the wrong side of
the NORTH repeater; pinned Minecraft bytecode confirms that its FACING is its
input. The separately documented R4 correction turns that single diode SOUTH.
No successful full gate cycle has yet been claimed.

R5 keeps the same wheel, pump, header, piston, moving plug, manual STOP lever and
four jet witnesses. Twelve real pipe nodes travel inside the pedestal and enter
the same header from the east, replacing the exposed overhead L. The pump-to-
header path has13 edges, within the pinned16-block range, and no output node is
adjacent to the intake pipe. The endpoint and one basin curb use full encased,
non-waterloggable pipe blocks. The header has full side walls and one enclosed
vertical descent. A room around the header would permit unwanted lateral flow.

The upper bowl contains a nine-cell, one-wide cross with twelve FULL waterproof
backing cells. Every arm has exactly one outward opening, rather than three
unbacked edges. These physical curbs must produce four clean ribbons in the
actual game; the source check is not a fluid simulator. No upper source is placed
by construction. Native commissioning must refill the dry header from the actual
powered pump. Once full, Create legitimately deadheads against the source; the
visible flow thereafter is gravity, not claimed continuous pump throughput.

The one-sided wheel baffle and its sealed independent supply remain. Lowering
and opening the rest of the wheel enclosure should reveal the real mechanism
without letting its wall obscure the centerpiece. Actual wheel flow, speed,
stress and stability must be checked again after this change.
