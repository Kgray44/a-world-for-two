# First west/original Tortuga living cohort

This source addition is independent of the frozen ten named characters. It does
not delay Bill, change those sites/profiles, or operate a world/runtime/client.
`tools.living_world_west_sites` reads the verified **89312d** stopped archive
through the existing `BackupWorld` reader: no extraction or live save access.
Original West15 and new West36-subset source footprints locate the premises;
every proposed cell is reread from the actual authenticated saved FULL chunks.
Source references, archive/region hashes and exact proposed files accompany it.

Six ordinary villagers use three original premises (Copper Crust, Bent Page,
Two Tides) and three newer ones (Crooked Kettle, Bent Spar Repairs, Seated Needle).
They are ordinary cooks, librarians, chart keepers, toolsmiths and menders using
the corresponding real vanilla jobs. No extra named personality replaces the
existing ten. Native job claiming is still actual gameplay, not a story label.

Each gets a **new dedicated two-part vanilla bed and job block** in literal saved
AIR:18 proposed blocks total. Existing beds, compatible job blocks, every saved
BE, known private player anchors/capsules and transport approaches are excluded
from assignment/new fixtures. All existing furniture, inventories and mechanisms
are retained. Full source floor/headroom/roof fields and connected same-floor
routes accompany the proposed room. Nothing sets Brain NBT, a profession, NoAI,
ownership, health, variants or a permanent chunk ticket.

Two freshwater candidates use separated actual western river volumes: one koi
and one pondie. Each has an explicitly read5x5x2 connected source-water volume,
clear surface and complete surrounding FULL field. **All50 water cells**, not
only the centre, must decode to a saved river biome. A nearby earlier locator
crossed a gravel-beach biome and was refused; its source receipt remains retained.
No fountain, turbine, decorative trough or ship model substitutes for habitat.
Master still checks current navigation, intakes, predators/otters, occupancy,
native biome/spawn rules and actual swimming. Existing fish are never cleared.

An insect (ladybug) and small bird have measured outdoor flight space beside
actual retained foliage. Dense low garden pockets did not meet the existing
native AIR clearance screen; no walls or plants were removed to make them fit.
The elevated candidates are **inspect-only until ordinary native spawn rules
pass**. A saved air/leaf field is not proof that a registered natural-spawn rule
permits that starting height. If refused, retain the failure and choose a genuine
later ground/perch habitat; do not force a spawn, add fake grass or weaken rules.

Master deployment uses the already installed v4 generic1..64 engine. Suggested
batches are three original villagers, three newer villagers, two fish, then the
two inspect-only flyers. Every batch has at most four town-authority source plans.
Rebind the current checkpoint and actual reviewed source geometry, verify actual
AIR-before/normal placement/full habitat, build the existing town authority and
whole-world UUID/predator/crowding census, then inspect before seed. There is no
new source-to-seed approval engine or alternate spawn command here. Proposed
identities use the original population namespace and existing `identity()`.

The geographic roaming envelope is derived from the source city outline. It is
an identity check, not an AI fence or proof that every enclosed cell is habitat.
Only the complete measured known field supplies initial habitat authority; mobs
keep their ordinary movement and natural chunk lifecycle.

Observe actual walking, work/HOME claims, sleeping/waking and no blockage; inspect
fish survival/swimming and genuine insect/bird behavior if admitted. After normal
restart verify the same UUIDs and persistent real behavior. Compare MSPT, CPU/RAM,
entities and loaded chunks between small batches; use the existing global,
per-species, per32m and current ramp budgets including the **seven existing actors
and all retained uncertain intents**. Never duplicate missing/unloaded residents.

This is a ten-candidate first west cohort, not extra56 or a replacement cap for
the owner's broader Living LIFE ambitions. Later cohorts continue through the
same measured habitat and budget process. Ordinary ambient dialogue stays
scripted; this source adds no API key, provider request or model configuration.

The observed Control Room registry has no geographic bounds on Tortuga. Named
UUID profiles still identify their district, but unbound ordinary villagers
cannot infer it. `tortuga-ambient-bounds-PROPOSAL.json` therefore supplies only an
`id`/`bounds` draft for the existing `/api/characters/district` endpoint, using
the accepted city geometry outline. It preserves lore, jokes, names and models
and never replaces already configured owner bounds. Master reviews actual
district overlap, supplies the fresh revision, saves and Applies through the
existing flow, then verifies the native hash and curated ambient dialogue.
No geographic dialogue bound grants construction or spawn authority.
