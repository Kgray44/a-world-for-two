# Western Tortuga ground and working edges

The first ground pass connects Captain's Rest's actual left porch, the shared
three-wide trade hook, Salt & Petal's south approach, the retained W3 public bend
and a winding return along the western shore. Each proposed path is two blocks
wide with three blocks of literal saved headroom. Existing roofs are retained
above the reviewed W3 approach; a visible roof is not mistaken for the ground.

Three individually authored open workplaces make these connections useful:
Old Brine has fish-sorting counters, a cutting board, contained rinse water,
waiting bench and a cropped footing which avoids a wet corner. Rag & Rig has
a real loom, canvas-repair bench, hung pennant and a one-way weathered lean-to.
The Crooked Cask has repair barrels, sharpening, a working counter and a
post-mounted rope ladder under a separate shaped canopy. Signs and task lights
have actual authored support. Every new container starts with native default
contents; no current inventory, ownership or crafting history is copied.

`tools.artistic_tortuga_west_ground` requires an exact current, verified stopped
private checkpoint. It checks actual FULL dry floors, supports, current block
identities, block entities and all existing/future masks before producing unique
private before, placement, retained-support, normal-join and full-verification
files. It never sends native commands or modifies the save. Existing authored
AIR stays protected except the explicitly listed shared walking AIR, which is
retained unchanged. Existing pavers are verified rather than replayed. Coral
and water divert the path; neither becomes a paving target.

The first source bundle has 373 path columns and 868 total targets. It needs
fresh native before/support checks, placement, normal joins, strict full
verification and real walking/workplace images. These connections and three
sheds do not complete the western village: the measured residual-land audit
and further linked, individually modeled frontages remain separate work.
