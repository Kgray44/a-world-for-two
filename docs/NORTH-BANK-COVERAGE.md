# Northern village source coverage

`tools.artistic_north_bank_coverage` subtracts the latest fourteen shore houses
and twenty new connections from the retained one-metre surface study. Its
private plan view distinguishes measured northern land, earlier authored
geometry, later additions, paths and unallocated dry profile centres.

The source inventory contains 72 modeled additions across seven groups. That
number does not establish their native placement, visual acceptance or the
completion of the circled land. The audit reads the named historical clean
checkpoint study; it does not inspect the current world or turn a watchdog save
into a clean source.

Every remaining red candidate is a previously measured 9×11 dry surface field,
with the full new geometry and one-metre model skirt excluded. Its complete
current body, trees, block entities, circulation and artistic composition remain
unqualified. Narrower gaps, tiny courts and the requested botanical and resident
LIFE passes need their own treatment. A region without a red centre is therefore
not automatically complete.

The diagram is explicitly a source plan, not a Minecraft image. Actual shader
views and walks should guide the next authored infill rather than duplicating
more houses before their composition has been seen.
