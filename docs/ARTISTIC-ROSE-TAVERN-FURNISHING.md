# The Drowned Rose: warm, lived-in rooms

This is an original furnishing proposal prompted by the untouched native c41 bar,
capstan and front photographs. The nave ribs, galleries and capstan have a strong
silhouette, but the floor is too dark and the room reads as mostly empty. High
roof lamps cannot substitute for light around tables and faces.

`tools/artistic_rose_tavern_furnishing.py` adds seven deliberately different small
scenes inside the actual saved hall. It changes no existing furniture, roof,
window, default block entity, tagged container, stock or capstan component.

| Scene | Human-scale composition |
| --- | --- |
| Returning crews' supper | Four green/red chairs, separated wood tables joined by a flush serving leaf, actual roast and drinks, small carved Mythrais posts and an overhead gothic frame. |
| Beneath the lancets | Red cushioned couch, separate green bench, facing chair, rice-roll platter, drinks and two reveal corbels beneath the retained gallery coffers. |
| First-round table | Two more colored seats and a small candle holder around the existing entrance-side table. |
| Rose barback | Carved post ends, low paneled display bases, wall-supported shelves, books, ship models, goblet, low lantern and readable glowing-ink notice. |
| Night-watch music corner | The existing piano and lectern stay clear. A small skeleton trophy, logbooks, notice and nearby low warm lamps give the stage a story. |
| West gallery reading pocket | A book table, green chair and compact lantern beside the existing couches, globe and chart stock. |
| East gallery corner | A separate compact lantern beside the retained table and circulation. |

The current proposal contains **86 new positions**, including **13 compact native
lanterns**: eleven at human level and two in gallery corners. The small existing
entrance-side table also receives a real Supplementaries candle holder. These are
ordinary local lights; the proposal changes no shader, gamma, weather or global
rendering setting. Actual block light levels and the final mood remain unmeasured.

The palette uses installed Mythrais carved columns, lintels, arch and corbels;
Handcrafted chairs, couch, bench, tables, shelves and books; Supplementaries goblets
and candles; Farmer's Delight shared meals; and Let's Forge Pirates ship models.
Registry properties are validated exactly, including the middle-column model's
absence of a mirror property. No downloaded third-party model or artwork is copied
into the repository.

The native Mythrais model files were inspected read-only to avoid enormous or
misleading fittings. The small curved/gothic corbels occupy narrow partial-block
forms; the carved upper column extends modestly above a block; the slim lintel
is shallow. That source inspection does not prove native survival, seating,
collision or lighting. Those still require actual settled state and screenshots.

## Custody and circulation

Preparation accepts only the independently owned artistic staging home and an
exact reconciled, verified stopped checkpoint. It reads saved region bytes from
the authenticated archive. Every target must be actual saved air, must lie inside
the finite tavern envelope, and must avoid all existing default/tagged block
entities. It does not replay the original tavern plan.

The retained service aisle, two-wide central walking lane, gallery routes and
stair approaches are hard exclusions. Every new vignette has a checked, two-high
adjacent approach after all furnishings have been added. Lamp/table supports are
checked explicitly; every new component also has a rooted voxel path to the
retained building. This is a coarse support proof, not an assertion about the
native fitting model's survival behavior.

The **complete saved original + placed depth + new furnishing** composite passes
the building's material rule: no material run exceeds nine, and only one axis
per material can have a run over three. Facing or state changes do not count as
different materials. Existing inventories, signs, window glazing and the old high
lights are never rewritten. Only the two new wall notices have explicit literal
SNBT tags; no inventory tags, entities or commands are added.

Preparation emits a fresh private immutable folder containing:

- `furnishing.json`: new pieces and only the two new sign tags;
- `before.json`: exactly the same target cells in their saved air states;
- `supports-VERIFY-ONLY.json`: unchanged floors, walls and root supports;
- `manifest.json`: checkpoint/source/member hashes, saved-region provenance,
  scene approaches, light positions and honest pending native checks.

The support plan is verification-only and must never be placed. The parent
operator must verify the exact current support/preimage, place the furnishing once,
inspect settled native states and both new notices, and take matching bar,
floor-level booth, stage/gallery and night views. Walking and seating must be
checked without blocking the piano, stairs or central aisle. Failed survival,
readability or visual composition remains a failure to refine; synthetic tests,
block counts and local light placement do not establish artistic acceptance.
