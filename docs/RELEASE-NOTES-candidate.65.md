# Candidate.65: current construction-world client

This Prism starter targets the currently running private construction server:
Minecraft 1.21.1, NeoForge 21.1.262 and Java 21. It includes the exact current
bridge 0.6.64, Easy NPC Core 7.17.1 and Drowned Rose tavern adapter 0.1.14 pins.
The starter downloads other gameplay files from their pinned author sources.
The owned QA client helper is excluded. The construction world is hosted by KG;
it is not included in the download.

Import the release's `A-World-for-Two-0.1.0-candidate.65-Prism.zip` into Prism as a
new instance. Select Java 21, sign into your own licensed Minecraft Java account,
and keep the Packwiz pre-launch command enabled. Sera should set the instance's
maximum memory to 4096 MiB. Shaders start disabled. In the game choose **Join Our
World**, then **Public (KG and Sera)**, or enter `malls-cup.tun.ply.gg` in Direct
Connection. The local server entry is for KG's host computer only.

The immutable Packwiz channel is
`https://kgray44.github.io/a-world-for-two/releases/0.1.0-candidate.65/pack.toml`.
This is an experimental prerelease for the current construction server. Exact
installed mod bytes were checked against the existing owner client and server.
Fresh installation, native startup and Sera's remote two-player acceptance have
separate results; publishing this download does not establish those outcomes.
No stable root update channel, existing player account or permanent world is
changed by publication.
