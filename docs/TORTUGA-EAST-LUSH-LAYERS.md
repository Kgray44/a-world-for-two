# Two further Tortuga botanical layers

`tools.artistic_tortuga_east_lush_layers` prepares two bounded, separate outdoor
planting layers for the Original Core, northern landmarks, eastern compounds and
north drawbridge approach. These are source proposals. They have not been placed
or visually accepted in Minecraft.

The first adds 799 cells: 47 small flower, shrub and contained-urn compositions,
plus 185 ivy scenes whose individual segments touch measured sturdy walls. The
second adds 242 cells: supported timber brackets, 15 hanging flower pots, small
upper foliage wings, four warm lanterns and 28 mature glowberry pendants. The
pendants contain 82 vine cells, of which 60 carry berries; their heads use age 25.

Both preserve the existing building footprints, windows, door approaches,
three-wide route reservations, water, mechanisms, saved block entities and
inventories. Garden pockets retain three literal clear columns beyond their
planted shoulder. New soil uses a measured dry substrate; upper displays attach
to retained full blocks. The two new placement sets are disjoint. Their leaf
distances are independently derived from the complete local state context.

Run the producer with `--home` pointing to the authorized private artistic staging
home and `--output` naming a new folder inside its `staging` directory. It checks
storage and live reader memory limits before reading the pinned stopped archive.
Private plans contain world metadata and must never be committed.

Complete the preceding ground, first botanical layer and entry/spine phases,
then obtain fresh native before verification. Each new layer has `before`,
`placement`, `normal` and `after` files. Pass 3's default before/after works without
pass 2; if pass 2 is already complete, use its `after-pass2` before/after pair with
the identical pass 3 placement and normal files. A failed current preimage is a
hold, not permission to replay or overwrite a changed cell.

The hanging pots use Amendments 2.2.2 and Moonlight 3.7.2. The exact pinned native
classes were inspected: the tile stores its cosmetic plant block state in the
`Mimic` compound. Only new, previously empty pot cells receive that tag; it contains
no inventory, owner or artificial entity behavior. The corresponding primary
sources are the [Amendments hanging-pot tile](https://github.com/MehVahdJukaar/amendments/blob/1.21/common/src/main/java/net/mehvahdjukaar/amendments/common/tile/HangingFlowerPotBlockTile.java)
and [Moonlight mimic tile](https://github.com/MehVahdJukaar/Moonlight/blob/1.21/common/src/main/java/net/mehvahdjukaar/moonlight/api/block/MimicBlockTile.java).

Artifact audits check hashes, disjoint writes, complete before/after composition,
rooted vines and hanging fixtures, new-only tags, mature berry heads and native
leaf-distance expectations. Native survival, tag round-trip, model clearance,
walking access and actual artistic quality remain pending in-world review.
