# Dense native forest patches

This is an isolated, original source proposal. It has not grown a tree or changed the active helper. The existing one-root controller and its failed/held receipts remain authoritative for their original sites; this workflow cannot retry those roots.

The requested goal is mature native trees at roughly4–5metre intervals throughout the eligible connected southern shore to the cliff foot, extending east to the measured eastern limit of the northern land. The old clipped forest study is insufficient. A new actual saved-terrain measurement must define the eligible component, coastline, cliff transition and exclusions. Neither a rectangle nor the number of proposed roots proves complete coverage. After native growth, actual mature-trunk positions and remaining eligible gaps need a new coverage report.

## Concrete native transaction

`NativeTreePatchSupport` processes1–32 explicitly selected roots under one shared maintenance lease. It hashes the pinned source artifact and obtains the real native grower/feature descriptors once per distinct sapling. All normal, rare, flower and root variants must retain their complete reviewed envelopes. It admits only the existing nine reviewed saplings.

For each root, it temporarily loads only that root’s finite known envelope, captures every current full native block state and actual BE data, and writes a durable compressed preimage. This captures the canopy left by earlier genuine growth instead of replaying an obsolete whole-patch state. A synchronous whole-field check, installed read/write-hook witness and durable once-only position intent precede the first physical setter. The ordinary sapling/bonemeal methods and native RNG then select the genuine feature. No tree geometry is stamped, no alternative variant is forced, and no consumed bonemeal stock is invented.

The new `TreeGrowthScope` overload accepts an exact captured set of permitted native foliage positions. Only original native leaves to native leaves can use that permission. Logs, fluids, every BE/hive, protected architecture, route bodies, machinery, fountain flow, bridge sweep, cable flight and view masks remain unwriteable. The legacy constructor passes an empty permission set and keeps its original strict behavior. `TreeBeeAudit` gains a separate dense-patch overload that permits reading existing BEs within an envelope while requiring their complete original bytes to remain unchanged; the default constructor still refuses them. Its native bee creation, stored occupants, live-UUID census and rollback checks are unchanged. The detached map uses the reviewed collision-safe snapshot helper.

Each root has a complete before/after archive. A failed native attempt restores only exactly owned setter targets, through the original typed rollback. Broken failure capture cannot skip restoration. Untracked changes, changed BEs, released entities or incomplete recovery retain the existing quarantine. The patch stops at the first failure/refusal; previous successful trees remain. Position intents prevent replay under another patch name. No legacy failed root is silently retried.

The implementation is finite:32roots,131,072known cells/current root,32temporary chunks/current root,7,200total ticks,16MiB maximum raw outcome,8MiB compressed archive,576MiB total archive bytes. Parent must run ReserveGuard with32MiB C and640MiB D forecasts before the native writer; the helper independently checks both30GiB reserves. Temporary tickets/futures and the lease are released on completion, cancellation or stop. Cleanup retries remain busy, and an immutable terminal receipt is published before the optional progress view.

Before any ticket or wake, `NativeTreePatchReadiness` reads CURRENT persisted chunk NBT through the real `ChunkStorage.read` API for the complete derived ticket/dependency/light halo. Every required chunk must already be FULL, DataVersion3955, correctly lit, have actual sections and matching coordinates. Unknown/retrogen/non-FULL chunks refuse. The gate allows four pending reads, at most4MiB per result,128MiB cumulative processed NBT,4,096columns and120seconds. It retains the same maintenance lease through that proof and subsequent normal loading; cancellation waits for its own pending reads to drain. `create=false` alone is never used as a no-generation claim. A live per-root field capture is not retrospective proof of absence of generation. This source does not authorize unsurveyed land or terrain flattening.

## Integration and protocol

Copy the new controller, native storage-readiness helper and both narrow overload proposals into a new immutable candidate. Keep `NativeTreeGrowthSupport` intact. Register command/tick/stop/busy handling and the shared interlock, and extend the private Control Room typed-command validator for `awfttreepatch inspect|grow`, `status` and `cancel`. Grow/cancel require the existing explicit local confirmation. Do not add unconditional empty-server waking.

`tools/native_dense_tree_patch.py` binds actual installed candidate/JAR/class hashes and the genuine versioned Packwiz release manifest. It creates a new immutable request and ownership receipt only; it submits no console command. It refuses before an actual installed patch class exists.

A source manifest uses format `awft-tree-patch-source-bundle:1`, current checkpoint ID/SHA and five bounded members (`path`, `bytes`, `sha256`):

- `plan`: `awft-native-tree-patch-plan:1`, actual private world/seed, spacing goal, distinct reviewed saplings and finite roots. Each root has an ID, actual root and soil full states, complete known/write bounds, sealed qualification and reviewed native foliage block IDs.
- `eligible_land`: `awft-measured-south-eligible-land:1`, actual connected eligible columns, current checkpoint/world, and truthful completed shore/cliff/eastern-edge measurement flags.
- `protection`: complete current full-growth/AIR/route/flow/flight/bridge/northern-partition protection, at least5metres around retained authored areas.
- `prior_root_custody`: every successful, failed, lost and held previous root. It must explicitly retain09,12,17 and the other existing holds.
- `patch_authority`: the parent-reviewed exact bare-patch/plan/checkpoint authority, allowing fresh per-root native captures and only native foliage overlap. It does not claim finished town/forest or owner artistic acceptance.

Run INSPECT first. GROW requires its genuine complete clean marked terminal receipt, matching all root IDs, current class, plan and checkpoint, completed within30minutes. GROW independently captures and checks every root again; inspection does not waive drift checks. Native tree results are not artistic, ecological or complete-density acceptance.
