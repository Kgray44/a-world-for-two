# Exact Create generated-pack custody overlay

This original source overlay covers the sole unsupported class in the actual
0.6.57 client attempt's complete 390 opened-pack headers:
`com.simibubi.create.foundation.pack.DynamicPack`, ID `create:dynamic_data`.
The ten-class roster is recorded in `actual-provider-coverage.json`; it does not
authorize arbitrary future provider types. TaCZ is before the failure and got
past inventory. CDP's two packs follow Create and remain native-traversal pending.

The pinned Create 6.0.10 implementation stores literal names and original native
suppliers in its `files` map. The view hashes **every** original member, including
root files and members without a valid resource ID. It checks native namespaces,
lists nested IDs through actual nonempty top-level prefixes, and directly reads
namespace-root files through native `getResource`. The native empty-prefix query
adds a second slash; its empty result is not treated as an empty pack. Native
listed/raw/selected supplier identities and bytes must agree. Repeated byte reads
use the existing accumulator, 512 MiB aggregate limit, count limits and 60-second
deadline. Map, metadata, producer identity and same-supplier byte mutation refuse.

The complete original Create JAR and class are pinned. Its synthetic metadata is
serialized using native `PackMetadataSection.TYPE.toJson`, distinct from an absent
raw `pack.mcmeta`. No pack is closed, data generator called, metadata invented,
resource normalized, fingerprint forced, or upstream JAR modified. Unknown
provider implementations continue to refuse; all opened headers remain logged
before traversal. Existing effective resource-stack attestation remains intact.

Integration is deliberately disjoint from the 0.6.58 canopy work: overlay only
`CreateDynamicPackCustody.java` and this fork of
`LithostitchedSeedgenResources.java` into the qualified private 0.6.58 mirror.
The latter is based on sealed 0.6.57's resource source and preserves original
nested-class line positions. Leave the complete TaCZ/CDP helper, DH yield plugin,
two canopy helpers and every other existing class unchanged. Bump only the
private builder, thirteen helper authority strings, TOML and manifest to 0.6.59.
Qualification must compare every old JAR entry against actual 0.6.58 and permit
changes only to the version-bearing class, resource outer/accumulator and metadata.

`CreateDynamicPackProbe` uses the actual pinned native class and public native
`put/list/get` methods with controlled inputs. Its fixture-only field setup avoids
a NeoForge-added constructor absent from the named compile API. Static vanilla
registry bootstrap permits the real component metadata codec; no world is started.
The fixture must prove the empty-query bug, nonempty-prefix coverage, direct root
lookup, selected-byte equality and byte/map/metadata mutation refusal. Compilation
and this fixture remain pending until the parent's genuine memory window; source
coverage is not native strict parity, generation, rendering or performance proof.
