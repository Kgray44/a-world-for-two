# Native LIFE spawn diagnostics

This is an isolated diagnostic-only proposal based on the exact candidate48 source. It is not installed or wired. The same three normal calls execute once each in the same left-to-right short-circuit order. No spawn predicate is rerun, no random value is sampled for diagnostics, and no darkness, block tag, event, collision, ownership or species requirement is bypassed. Failure records identify the actual rejected stage and read the live light/time/biome/underfoot context without changing it. A context-read failure is retained separately and never replaces the original refusal.

The original eight-member native48 refusal cannot retrospectively be assigned to one branch. Firefly darkness is a source-backed explanation, not a captured live-cause proof. New input/native class pins and actual runtime review are mandatory before this diagnostic source can be used.
