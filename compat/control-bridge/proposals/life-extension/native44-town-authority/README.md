# Explicit town authority for the single LIFE controller

This additive source proposal derives a v3 controller/producer from the exact frozen native44 `079ef869…` source. It does not modify that seal or active43, register another listener, use a second population namespace, install a request, or spawn a resident. The same sixteen inspected profiles/fifteen enabled species, seven source JAR pins, native hooks, durable per-UUID intents, whole-cohort cap and ownership/AI rules remain. Town cats, dogs, ordinary villagers and music-default Ribbits can use explicitly reviewed usable rooms and lanes; no profession, tame owner or NoAI value is assigned.

Each member supplies exactly one authority: the existing actual `bank_anchor` for WOODLAND, or an explicit `town_site` for TOWN. Woodland geography and its four-species legacy queries are unchanged. The town overload accepts finite native coordinates only together with a complete source-backed authority; a wider rectangle grants no permission. The frozen woodland source remains bound for the combined cohort but is never borrowed as proof that the northern harbor belongs to that forest component.

`TownLifeAuthority` reads a bounded `awft-town-life-authority:1` index. At most four exact authored FULL native plans,16MiB total/250,000 addressed cells, provide actual geometry and authored AIR. Each source needs its immutable native full physical verification with the exact plan hash/count, successful status and completion digest. Historical physical source proof does not claim present whole-plan or functional acceptance. Every current resident still needs the existing exact stopped **FULL** habitat volume, current native habitat verification, collision/medium/footing tests and ordinary spawn hooks.

An index contains1..16 individually reviewed site ids. Each names authenticated sources, explicitly permitted species, exact `known_bounds`, explicit `occupancy_cells` and up to64 `standing_positions`. Every occupancy cell must be addressed by an actual authored source, including real cleared AIR. Standing points also need authored floor/body/head cells. At runtime the actual model's body, flight core, water cells, seed footing, route points and bed/job/roof witnesses must stay inside that reviewed mask. Unknown/unwritten cells are refused. The native sturdy floor, obstruction, contiguous source water, shelter and real free POI checks remain independent; a source mask alone cannot claim those passed.

Only motion/navigation/current R5/future-cable exclusions apply as hard LIFE keepouts. The forest's broad all-authored-AIR tree protection is deliberately not reused to ban all house interiors. Working controls, moving envelopes, waterways, routes and forbidden plumbing remain protected by the same complete safety index. Real furniture/default BEs stay in the actual preimage and collision model; no source inventory/NBT is replayed.

Town source authority is immutable across restart and records its original `source_checkpoint_sha256`. Each new request separately binds the **current** stopped checkpoint and complete current FULL field/native verification. The producer re-reads all retained recipe cells from the current stopped save and refuses any changed/unknown state. Retaining the identical source authority/recipe keeps the existing per-UUID durable intent byte-identical; changing authority is not permission to replace an existing resident or silently migrate its identity. Ordinary AI may later leave a reviewed roaming habitat; a later inspection preserves that uncertainty rather than teleporting the resident back.

Run the repository `prepare.py` here with the ordinary native44 arguments and optional `--town-authority <reviewed-index>`. Its sites format is `awft-life-sites:3`; request/recipe formats are v3, so old v2 inputs cannot silently upgrade. The default remains `inspect`. Seed still needs completed construction/function/art/habitat approval and fresh actual native habitat verification. No room site is inferred from a bounding box or source-plan name. No actual town index, site batch or seed request has been prepared by this proposal.

`prepare_source.py` produces the three derived Java classes plus audit copies of the producer/helper in a new private D folder. Parent must integrate the Java classes atomically and pin `native_town_authority_sha256` with the other actual compiled classes. Use this repository's producer location; private copied Python files are custody material, not an alternate launcher. Existing one-instance command/tick/stop/interlock/cleanup wiring stays unchanged. No version, catalog, Packwiz, export or running instance is changed here.
